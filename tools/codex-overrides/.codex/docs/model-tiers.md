# Codex models and studio responsibility

Every native role inherits the current Codex session model by default. No Claude
model aliases apply. Skill frontmatter does not select a model. The manifest's
upstream_metadata retains original labels solely for traceability.

Director, lead and specialist tiers define scope and escalation paths. They are
not a pricing or capability guarantee. If the user chooses separate models,
verify account availability and supported reasoning settings before configuring
role TOML files. Never silently substitute a model or change the session.
